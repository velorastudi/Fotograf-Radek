Fotograf Radek – webová prezentace

Česká verze fotografického portfolia upravená pro značku Fotograf Radek.
Projekt obsahuje hlavní stránku, styly, skripty, obrázky a podklady potřebné pro spuštění webu.

Spuštění:
Otevřete soubor index.html v prohlížeči nebo nahrajte celý obsah na webhosting či GitHub Pages.
